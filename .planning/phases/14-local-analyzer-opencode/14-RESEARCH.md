# Research — локальный analyzer через Docker tunnel

Пользователь уточнил: сайт/worker на удалённом сервере, OpenCode исполняется на этом компьютере, связь через Docker tunnel; нужен start-analyzer по образцу Bondscan. Предыдущий scope остаётся: exact moondream/parakeet-ultra и nvidia/nemotron-3.5-transcribe в конфиге и выборе ASR.

Исходники Bondscan прочитаны без .env/auth/ключей и без изменений. start-analyzer.sh в доступной копии старый: host SSH -L для remote DB/MQ, host Rust analyzer+crawler. Optional analyzer compose использует host.docker.internal к тем forwards. На скриншоте другие containers bondscan-runners/codex-runner иtunnels; их актуального Docker source здесь не найдено. Доступный reference подтверждает one-command запуск и локальный execution, но не точную текущую Docker topology. Простое копирование DB/MQ tunnel не подходит Phone worker с private media path.

Выбран независимый HTTP reverse transport: remote worker держит DB/очереди/медиа, вызывает model-runner по внутреннему Docker DNS; SSH relay переносит запрос в local connector, результат возвращается серверу. Данные/credentials Bondscan не используются. Классический reverseSSH на remote127.0.0.1 недоступен обычному remote Docker worker: нужен отдельный SSH relay container в сети приложения. Его SSH публикуется наremote127.0.0.1; reverse HTTP4096 слушает только внутри container, наружу не публикуется. Локальный клиент через SSH jump-host достигаетrelay, поднимает -R0.0.0.0:4096:model-runner:4096. Alias model-runner наremote relay сохраняет существующий API/worker internal URL. Локальный connector иlocal SSHclient — независимый Compose project, без DB/media/Bondscan mounts.

OpenCode pinned1.18.10 реальный /doc и source исследованы: нет native STT endpoint, session provider — LanguageModelV3/streamText. Не выдавать произвольные STT models за chat. Nativeconfigv1 поддерживает provider.openrouter.models, attachment/audio modalities/tool_call=false; no invented tokenlimits. Current V2 docs отличаются: pinned version не обновлять.

Обе exact модели опубликованы в OpenRouter: https://openrouter.ai/moondream/parakeet-ultra и https://openrouter.ai/nvidia/nemotron-3.5-transcribe. Официальный STT contract https://openrouter.ai/docs/guides/overview/multimodal/stt: POST /api/v1/audio/transcriptions, JSON base64 input_audio или multipart, json/verbose_json, segments/words где доступны, usage/cost. NativeOpenCode не является STT engine; добавляется явное ASR расширение Docker connector на том же4096 с nativeOpenCode localhost4097. Указанные модели также входят в реальный opencode.json каталог.

ASR api_key — отдельный зашифрованный ключ OpenRouter компании; transport использует MODEL_RUNNER_PASSWORD из server runtime только к trusted connectorURL. Ключ компании передаётся отдельным header, не сохраняется в nativeOpenCode env/config и не смешивается между запросами. Legacy analysis.opencode auth не менять. При смене ASR provider не наследовать ключ старого провайдера молча.

Технические границы: audio<=24MiB/chunk, bounded base64JSON/ответ, maxconcurrency до bodyread, deadline+abort, fixedOpenRouterhost/redirectdeny, staticerrorcodes, numeric speaker labels сохраняются строками, manager/client не угадывать, unsupportedverbose400 не повторять скрытым платным запросом. Файлы/номера/токены не выводить в логи.

Remote SSH target и текущий Docker config со скриншота отсутствуют; отправлен короткий asyncвопрос. Разработку и локальную SSH-integration проверку продолжаем. Реальный remote pairing/ASR key/quality — отдельные live gates, их отсутствие не заменяется synthetic evidence.
