## Findings

1. **Medium, privacy:** новый host nginx `error_log ... warn` может сохранять полную строку запроса с query при upstream errors. В query встречаются phone search/filter и reset/invite links. Access log уже безопасно исключает query; error log следует привести к `crit`, как в client nginx. Перед открытием проверить фактический установленный файл.
2. **Medium, cutover:** исходный capture возобновляет localworker сразу после снимка, а finalize позже требует неизменный digest call/recording/connection/transcript/analysis. Рабочий импорт уже продолжался во время исследования. Если localworker продолжит работу между capture и finalize, получится ожидаемый отказ завершения после запуска remote. Требуется явная остановка localworker сразу после capture/через cutover или сохранение quiesce до успеха с возвратом state при ошибке. Автоматический обход digest недопустим; повторный restore поверх target тоже недопустим.
3. **High, relay startup; найден root при runtime:** public SSH key передавался600 ownerdks1001, а rootless relay10001 не мог прочитать bind file. Исправлен только собственный PUBLIC pubkey644, private runtime600. Transfer допускает public-mode исключительно для exact `secrets/analyzer-ssh/id_ed25519.pub`, проверяет hash и regular-file/symlink, повторный вызов безопасно исправляет прежний600.
4. **High, API/worker startup; найден root/migration author при runtime:** inline YAML tmpfs без кавычек разбивался по запятой на2specs; configquiet не доказал возможность создать Docker container. Обе строки исправлены на quoted single mount (API64MiB/worker512MiB); actual API healthy и тест настоящего Compose parser подтверждают fix.
5. **High, nonroot runtime; найден root при runtime:** git archive извлекался под umask077 без сохранения mode, source files становились600 и COPY сохранял нечитаемость для nonroot runner. Исправлены tar-xpf, immutable revision source contexts и staging lock. Relay Dockerfile задаёт COPY --chmod0644 для Python/sshd config и проверяет compile/read после USER10001; assistant chmod ограничен только public code/package files и проверяет node/Codex после USER10001. Auth volume/private credentials не меняют права.
