# Phase15: финальная проверка владельцем

Открой https://phone.bondscan.ru. Логин и новый пароль — локальный приватный `secrets/production-access.json`, `accounts` → `owner@demo.local`. Старый учебный пароль на сервере не действует. Секреты не присылай в чат.

1. Войди, проверь дашборд и журнал, переключи компанию: данные и настройки должны меняться вместе с компанией. Найди звонок «Можно слушать», открой карточку и послушай запись.
2. Открой помощника: авторизация Codex перенесена. Отправь обычный запрос, например «Покажи настройки компании». Изменение тегов/фильтров проверяй на выбранной компании осознанно: помощник выполняет такие команды.
3. На этом компьютере должен работать Docker и `./start-analyzer.sh`; `./start-analyzer.sh doctor` проверяет настоящий сквозной туннель. В настройках расшифровки выбери OpenCode → OpenRouter, одну из двух моделей и введи ключ OpenRouter компании; затем проверь соединение и расшифруй одну выбранную запись. Codex-подписка не заменяет OpenRouter-ключ. Качество текста и оценки проверяется по записи и твоим критериям.

Автоматически уже проверены HTTPS, вход/защищённые cookies, три сменённых пароля, разграничение компаний, аудио Range206, сохранённый Codex status, frontend1440/390, обе модели в UI и настоящий remote→local Docker SSH tunnel. Платные model requests для smoke не выполнялись. Статус доступности моделей не доказывает качество/доступ конкретного OpenRouter-аккаунта.
