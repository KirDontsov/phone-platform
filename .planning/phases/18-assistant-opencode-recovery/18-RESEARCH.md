# Phase18 — Codex / уже подключённый OpenCode

Пользователь подтвердил другой уже подключённый провайдер OpenCode. В глобальном ~/.config/opencode/opencode.json есть routerai, freellmapi, apinex; реальные credentials читались только в памяти для исходного endpoint. APInex /models200,43models; freellmapi localhost недоступен. Среди моделей этих конфигов нет Parakeet/Nemotron ASR. Ключ OpenRouter навязан существующей реализацией ASR-адаптера, не является требованием самого OpenCode. В analysis поле api_key фактически внутренний pairing, уже подставляется сервером; пользователю оно не нужно.

Авторизация Codex действительно падает до выдачи devicecode: anonymous remoteOIDC403 vs local200; настоящий pinnedCLI account/login/start →JSONRPC-32603/HTTP403. Схема корректна. У новой компании сохранённого auth.json нет; нельзя заявлять, что upgrade удалил действующий login. Подробности независимого исследования18-AUTH-RESEARCH. Successfulturn сохраняет refreshedauth, поэтому первоначальная гипотеза отсутствующегоrefresh опровергнута.

Минимальное восстановление Codex: существующий SSH relay переносит rawTCP4096, поэтому добавить authenticated CONNECT на локальном gateway, только auth.openai.com/api.openai.com/chatgpt.com:443, boundedtimeouts/concurrency/cleanup. TLS не расшифровывается. RemoteCodex получает только явно сконструированные proxyenv из собственного pairing; MCP кAPI ходит напрямую. Никаких auth/keyкопий Bondscan и новых OpenAIAPIключей.

Повторное использование локальных настроек: отдельная runtime600 копия только providerdefs/credentials из глобального OpenCode, ограниченная organization_id компании; не копировать tools/plugins/instructions/MCP/authхоста. Применить собственный denyconfig, модельные запросы импортированных провайдеров допускаются только с tenantheader, который задаёт API/worker. Собственные ключи не возвращать в /config/catalog/browser/log. UI показывает доступные localprovider/models без ввода APIkey. Условный ASR через существующийAPInexvoice должен называться собственным именем; нельзя выдавать его за Parakeet/Nemotron или автоматически переключать на платныйSTT. Исходные две модели и per-companyOpenRouter остаются явной отдельной опцией.

Первичные источники: https://learn.chatgpt.com/docs/auth?surface=cli ; https://opencode.ai/docs/providers/ ; https://openrouter.ai/docs/guides/overview/multimodal/stt ; https://apinex.bond/developers/tools/voice . Последний endpoint требует проверки фактической схемы перед реализацией. Ни inference, ни STT платных запросов в research не было.
