# Проверка RouterAI

1. Подтверди Phone Platform на открытой странице RouterAI со своим существующим аккаунтом. Ничего копировать в чат или поле API-ключа Phone не нужно. Доступ и лимит расходов выбираешь на стороне RouterAI. Если окно уже закрыто/ссылка истекла: на этом компьютере из проекта выполни `./start-analyzer.sh connect-routerai` — новый вход без ID и секретов.
2. После сообщения об успешном подключении обнови настройки Phone. Для анализа выбери OpenCode и свою текстовую модель RouterAI. Для расшифровки — OpenCode → Уже подключённый провайдер → RouterAI · Parakeet Ultra или RouterAI · Nemotron 3.5 Transcribe; сохрани выбор. Повторный ввод ключа отсутствует. Проверка соединения не отправляет аудио.
3. Открой одну запись «Можно слушать», запусти расшифровку и проверь результат/таймстампы; затем анализ. Это пользовательский реальный запуск у RouterAI с его расходами и лимитом. Оператор его не делал, качество/правоаккаунта не объявлены доказанными по fixtures.

Компьютер и Docker должны работать для локального коннектора и туннеля. Чужая компания не получает этот доступ. Согласие RouterAI — отдельный externalgate; пока helper пишет awaiting_consent, аккаунт ещё не подключён. Старые pending/live-gates других фаз остаются отдельно.
