# Phase20 UAT

Автоматические проверки не закрывают пользовательскую приёмку и внешние лимиты.

1. `./start-analyzer.sh connect-routerai`: использовать новое открывшееся окно, войти и подтвердить выдачу доступа. Дождаться «RouterAI подключён». Ошибка содержит понятную причину; ключи/полные callback URL в чат не отправлять. Истёкшее окно нужно заменить новым запуском.
2. В журнале фильтр «Запись → Можно слушать»: открыть звонок и включить запись. Это скачанные файлы; состояние общего лимита Телфина не должно мешать плееру.
3. «Ожидает Телфин»: запись ещё не скачана, запросы ограничил провайдер. Повтор выполняется автоматически после паузы; точное время окончания полной загрузки не обещается. Не запускать повторный полный импорт ради обхода паузы.
4. Если конкретная вчерашняя запись показывает ожидание: требуется ссылка на карточку внутри Phone (без номера клиента в публичном сообщении) для адресной проверки; aggregate проверка файлов не идентифицирует названный пользователем звонок.
