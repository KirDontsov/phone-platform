# Доступность записи в журнале — 2026-11-12

Узкое дополнение CALL-01/CALL-03: пользователь должен отличать готовую запись от ожидания, ошибки и отсутствия без открытия каждого звонка. Фаза12 остаётся приостановлена.

В списке появилась колонка «Запись» и фильтр: «Можно слушать», «Загружается», «Лимит Телфина», «Ошибка загрузки», «Нет записи», «Не загружена». На мобильном статус находится под клиентом. Для применения быстрого фильтра нужно нажать «Найти».

API вычисляет recording_state одним дополнительным organization-scoped чтением recording документов, без N+1 и без раскрытия URL/путей. Готовая запись имеет приоритет; затем rate_limited, pending, failed. При отсутствии recording документов только явное has_recording=false означает none; остальные случаи unknown. stage и has_recording не доказывают готовность. Сохранённое клиентом/провайдером поле recording_state не принимается за достоверное. API list/detail, конструктор фильтров и MCP описание используют одинаковый контракт.
