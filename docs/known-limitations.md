# Границы проверки

Приложение, локальный PostgreSQL/RabbitMQ, HTTP API, worker и Vue проверяются автоматически на синтетических данных. Demo-аудио — искусственный сигнал, а текст/оценка — явно обозначенные учебные примеры. Это не доказательство распознавания речи.

Реальные аккаунты Телфин, ASR/LLM, amoCRM и Google не подключались по указанию пользователя. Поэтому пока не подтверждены доступная глубина истории, полнота конкретной АТС, квоты и реальные OAuth scopes, качество русской речи/ролей/оценки, стоимость выбранных моделей и доставка в конкретную сделку/таблицу. Адаптеры реализованы; отсутствие настройки даёт видимую ошибку, а не подставной успех.

Периодический импорт опрашивает последние два дня с overlap. Запись, появившуюся позже за пределами окна, получают повторной синхронизацией нужного периода. Первичность при неполной истории остаётся unknown; answered в IVR не считается доказанным разговором сотрудника. Неизвестные роли требуют подтверждения до уверенной оценки. OpenCode runner не получает инструменты, репозиторий, БД или Docker socket; доступность конкретной модели зависит от локальной настройки её провайдера.

Нагрузочный профиль 5000 синтетических звонков/4 параллельных запроса — измерение локального стенда. Объём, длительность, пики реальной компании и квоты ASR пока не заданы. API фильтрует историю компании в памяти; при существенно большей истории нужны измерение и перенос фильтрации/агрегаций в индексированные SQL read models. Публичный SaaS onboarding, биллинг, real-time подсказки и исходящие звонки не входят в v1.

Финальный пользовательский UAT и разрешённый пилот на реальных записях остаются последним этапом приёмки. Данные удаления после даты backup можно восстановить только при наличии актуального отдельно сохранённого deletion ledger.
